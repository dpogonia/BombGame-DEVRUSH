# Bomb Game

Игра на скорость: нужно успеть назвать ответы, пока не взорвалась бомба. Командный учебный проект, команда 3.

## Что умеет приложение

На старте выбирается категория: кино, музыка или путешествия. В игре идёт таймер, бомба на экране анимируется. В настройках задаётся время, музыка и выключение анимации. Отдельный экран с правилами.

## Стек

UIKit, Storyboard, Lottie, AVFoundation, Swift Package Manager.

## Запуск

```bash
git clone https://github.com/dpogonia/BombGame-Team3.git
cd BombGame-Team3
open "CHALLENGE №1 .xcodeproj"
```

Запустите схему **CHALLENGE №1** на симуляторе iPhone. При первом открытии Xcode подтянет пакет Lottie.
