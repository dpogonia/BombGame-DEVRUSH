Игра, в которой нужно успеть ответить на вопросы, пока не взорвалась бомба. Проверка знаний и скорости реакции.

## Возможности

- Задать время на ответ.
- Выбрать категорию вопросов.
- Выбрать музыку из предложенных вариантов.
- Включить и выключить анимацию.

## Установка

```bash
git clone https://github.com/dpogonia/BombGame-DEVRUSH.git
cd BombGame-DEVRUSH
open "CHALLENGE №1 .xcodeproj"
```

При первом открытии Xcode подтянет пакет Lottie. Запустите схему **CHALLENGE №1** на симуляторе iPhone.

## Как играть

1. Запустите приложение и выберите режим.
2. Выберите категорию вопросов и начните игру.

## Требования

- iOS 15.0+
- Xcode 13.0+
- Swift 5.0+
